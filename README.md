# My-Chatbot 🤖

My-Chatbot is an AI conversational assistant powered by **Groq LLM** that provides fast and intelligent responses through a simple Streamlit interface.

The chatbot leverages Large Language Models (LLMs) via Groq's high-performance inference engine to deliver low-latency conversations with a clean and user-friendly UI.

## 🚀 Features
- ⚡ Fast responses using Groq LLM inference
- 💬 Natural language conversations
- 🧠 Context-aware chatbot experience
- 🌐 Interactive Streamlit web interface
- 🔐 Secure API key management using environment variables

## 🛠️ Tech Stack
- Python
- Streamlit
- Groq API
- Large Language Models (LLMs)
- dotenv
